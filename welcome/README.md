# Страница первого входа

Адрес: **https://club.topcheese.online/welcome** (сервер может добавить завершающий `/`).
Локально: **http://localhost:8791/welcome/** при запущенном сервере из корня репозитория.

Страница входит в существующую сборку `npm run build` и размещается в `dist/welcome/`.
Используется текущий проект ONREZA и действующий HTTPS домена клуба. Новые DNS-записи, поддомен и отдельный хостинг не нужны.
Оформление основного лендинга не изменяется. Документация и тесты в сборку не попадают.

## Где менять ссылки

Ссылки видео, платформы и помощи: **`welcome/config.js`**.

| Настройка | Назначение |
| --- | --- |
| `video.embedUrl` | Общая VK-видеоинструкция для компьютера и телефона |
| `video.title` | Название видео для доступности и заглушки |
| `video.aspectRatio` | Пропорции плеера, например `16 / 9` |
| `platformUrl` | Кнопка «Перейти на платформу» |
| `telegramUrl` | Кнопка помощи Telegram |
| `maxUrl` | Кнопка помощи MAX |
| `intro.status`, `intro.title`, `intro.description` | Приветствие и сообщение об оплате |

Для видео нужен **только URL из атрибута `src` кода встраивания VK**, например:
`https://vk.com/video_ext.php?oid=…&id=…&hash=…`.
Поддерживаются также `vkvideo.ru/video_ext.php` и варианты с `www`.
Не вставлять весь `<iframe>` или обычную ссылку просмотра. Если в скопированном `src` есть `&amp;`, заменить на `&`.
Пустая или некорректная ссылка оставляет заглушку. После замены ролика проверить его доступность для посетителя без аккаунта VK.

Подключена одна общая инструкция: VK `-212599640_456239050`, реальные пропорции кадра 1920:1002 (проверены по videoWidth/videoHeight плеера). Контейнер повторяет их, чтобы убрать чёрные полосы без обрезки кадра. Скругление общее для контейнера и iframe; тонкая обводка не отнимает место внутри плеера.
Видео сразу доступно на компьютере и телефоне, без переключателя устройств. В ссылке сохранён присланный пользователем `autoplay=1`; фактический автозапуск зависит от политики браузера.
Поворот экрана и изменение окна меняют размеры плеера, не заменяя iframe и не сбрасывая воспроизведение.
Ссылки на платформу и помощь открываются в новой вкладке, чтобы инструкция оставалась под рукой.
Юридические ссылки, реквизиты ИП и ИНН перенесены с основного лендинга в подвал `welcome/index.html`. Оферта и политика открываются в новой вкладке.

## Содержание и повторное использование

Основные шаги и блоки находятся в `welcome/index.html`, оформление — в `welcome/welcome.css`, подключение видео и ссылок — в `welcome/welcome.js`.
Для будущей общей инструкции можно использовать тот же HTML/CSS/контроллер и другой конфиг `intro`: убрать статус (`status: ""`) и заменить вступление. Дублировать подключение видео и блоки инструкции не требуется.

«Оплата прошла» — текст страницы для успешного редиректа, а не проверка транзакции.
Нет авторизации, форм оплаты, Метрики или целей покупки.
«Настройки cookie» используют общий `club-prototype/cookie-consent.js` и тот же ключ localStorage, что и основной лендинг. На этой странице работает только диалог настроек, без стартового баннера и без загрузки аналитических/маркетинговых интеграций. Выбор сохраняется после обновления и действует на основном лендинге. Общий контроллер поддерживает отсутствие баннера; его поведение на лендинге сохранено.
Редирект после успешной оплаты на стороне GetCourse этой задачей не меняется.
Страница исключена из индексации через `noindex, nofollow`.

## Проверка и публикация

1. Запустить статический сервер из корня репозитория (например `python3 -m http.server 8791`).
2. Открыть локальный URL, проверить видео на компьютере и телефоне, а также три внешние ссылки.
3. Выполнить `node --test welcome/tests/welcome.browser.cjs` в окружении с Playwright и установленным Chromium.
4. Выполнить `npm run build` и `npm test`.
5. Существующий push в `main` запускает GitHub workflow → ONREZA. Проверить публичный `/welcome` после завершения деплоя.

Тесты проверяют 320/360/390/430/768/1280/1440 px, отсутствие переполнения, ссылки, один общий VK iframe, сохранение плеера при resize и отсутствие внешних запросов при заглушке. Отдельно проверяются юридические ссылки, реквизиты, сохранение cookie-настроек, восстановление фокуса и использование выбора на основном лендинге. В тестах используются пустая конфигурация и фактическая ссылка общего видео, а VK подменён локальным ответом. Доступность и воспроизведение настоящего ролика проверяются отдельно в браузере.
